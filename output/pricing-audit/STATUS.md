## Previous 0.1.0 staging candidate notes (historical)

2026-09-04. Live site untouched. Source: wordpress-plugins/off-label-best-offer. No changes made to existing checkout, builder, ACO, ELEX, bridge or Site Controls for this pricing work.

Default disabled, production environment refused, exact WooCommerce 11.1.0 required. Installed Build Your Box (if present) must be 1.3.3; ACO (if present) 1.1.0; ELEX (if present) 1.3.2. Enable only on a staging copy using WooCommerce > Off Label Pricing. Existing product volume defaults are yes with 3/10%, 5/15%, 10/20%; variations inherit parent settings and qualify independently. Coupons-over-volume toggle defaults yes. Per-product settings and coupon explicit exclude-box control are available even with engine off, but do not affect pricing until enabled.

Engine resets line objects to original regular prices, compares sale/volume/whole-box/payment offers against independent native coupon quotes, then routes chosen allocations through native custom coupon maps. Automatic offer is a virtual native coupon. Coupon objects change type only for disposable calculation instances, never saved. Real coupons retain their eligibility, minimum spend, individual-use and free-shipping fields. A coupon that applies only to excluded boxes fails validation (cannot unlock free shipping). Mixed carts with an eligible coupon retain native cart-level free shipping behavior.

User chose product/group-level winners. Box remains one group; excluded member or explicit excluded box/Bundles category removes whole group before coupon/BOGO quoting. Fixed-cart amounts retain native independent allocation without redistributing discarded shares. BOGO supplied by Advanced Cart Offers, not PW BOGO. Ordinary quantity tiers exclude box components from standalone SKU aggregation.

Audit used live read-only plugin/settings inspection in preceding work. offduty: 30%, min spend 50, individual-use, free shipping, excludes BAC-30 product ID338 and BUNDLES category. ELEX Zelle percentage5 enabled. PW BOGO active but no published offers; user no longer uses it. Code Snippets inventory and affiliate non-coupon price rules remain unverified. Unknown price changes/negative fees block checkout instead of silently stacking. Fixed ELEX discount rules deliberately block checkout pending a tax-aware adapter; current audited rule is percentage.

Local tests: scripts/verify-best-offer.php uses actual upstream WC_Discounts 11.1.0 and actual user-provided ACO 1.1.0 with mocked WP, products, coupons and session. 57 assertions for business behavior/order replay/guards plus 4,000 assertions over 1,000 deterministic rounding allocations.
