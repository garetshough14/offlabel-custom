# Off Label Website Product Image Library

This folder is the canonical product-image handoff for the website migration.

- All images are JPEG files measuring exactly 1150 x 1600 pixels.
- `images/` contains one canonical image per bottle design.
- `product-image-manifest.csv` maps each website product to the correct image.
- RT-3, Sermorelin, and TZ-2 use strength-neutral labels because customers select the strength on the product page.
- BAC Water uses the simplified `BAC` label requested for the site.
- NAD+ Bundle reuses the NAD+ image, and RT-3 Bundle reuses the strength-neutral RT-3 image.
- Strength-specific RT-3, Sermorelin, and TZ-2 files are intentionally excluded from this upload set.
- CJC-1295 / Ipamorelin, N-Acetyl Semax Amidate, and SNAP-8 are included as Drive-only future assets.

Use the manifest during the WooCommerce media replacement so each product receives the listed canonical image.
